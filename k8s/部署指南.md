# AIMS K8s 部署指南

## 环境要求

- Kubernetes 1.20+
- Helm 3.0+
- 存储类 (StorageClass) 配置
- Ingress Controller (推荐 nginx)

## 快速部署

### 1. 使用 kubectl 直接部署

```bash
# 创建命名空间
kubectl apply -f k8s/namespace.yaml

# 部署配置
kubectl apply -f k8s/configmap.yaml
kubectl apply -f k8s/secret.yaml
kubectl apply -f k8s/configmaps.yaml

# 部署存储
kubectl apply -f k8s/pvc.yaml

# 部署服务
kubectl apply -f k8s/deployments.yaml
kubectl apply -f k8s/services.yaml

# 部署网络和入口
kubectl apply -f k8s/network-policy.yaml
kubectl apply -f k8s/ingress.yaml
```

### 2. 使用 Helm 部署

```bash
# 添加 Helm 仓库（如果需要）
helm repo add aims-repo https://charts.example.com/aims

# 安装
helm install aims helm/aims -n aims --create-namespace

# 自定义配置安装
helm install aims helm/aims -n aims --create-namespace \
  --set openclaw.replicaCount=3 \
  --set mysql.persistence.size=20Gi \
  --set ingress.enabled=true
```

## 配置说明

### 环境变量配置

编辑 `k8s/secret.yaml` 或 `helm/aims/values.yaml` 来配置敏感信息：

```yaml
# LLM API Keys
DEEPSEEK_API_KEY: "your-deepseek-api-key"
MOONSHOT_API_KEY: "your-moonshot-api-key"
ZHIPU_API_KEY: "your-zhipu-api-key"

# 渠道配置
FEISHU_BOT1_APP_ID: "your-bot-app-id"
FEISHU_BOT1_APP_SECRET: "your-bot-app-secret"
WEWORK_CORP_ID: "your-corp-id"
WEWORK_AGENT_SECRET: "your-agent-secret"
```

### 资源配置

根据实际需求调整各组件的资源限制：

```yaml
openclaw:
  resources:
    requests:
      memory: "512Mi"
      cpu: "500m"
    limits:
      memory: "2Gi"
      cpu: "2000m"
```

## 访问服务

### 配置本地 hosts

```bash
# 添加到 /etc/hosts (Linux/Mac) 或 C:\Windows\System32\drivers\etc\hosts (Windows)
<ingress-ip> aims.openclaw.local
<ingress-ip> aims-minio.openclaw.local
<ingress-ip> aims-milvus.openclaw.local
<ingress-ip> aims-qdrant.openclaw.local
```

### 访问各服务

- **OpenClaw Gateway**: http://aims.openclaw.local
- **MinIO Console**: http://aims-minio.openclaw.local
- **Milvus Dashboard**: http://aims-milvus.openclaw.local
- **Qdrant Dashboard**: http://aims-qdrant.openclaw.local

## 扩展和升级

### 水平扩展

```bash
# 扩展 OpenClaw 副本数
kubectl scale deployment aims-openclaw --replicas=3 -n aims

# 或使用 Helm
helm upgrade aims helm/aims -n aims --set openclaw.replicaCount=3
```

### 启用自动扩展

```bash
helm upgrade aims helm/aims -n aims \
  --set openclaw.autoscaling.enabled=true \
  --set openclaw.autoscaling.minReplicas=2 \
  --set openclaw.autoscaling.maxReplicas=5
```

### 更新配置

```bash
# 修改配置后重新部署
helm upgrade aims helm/aims -n aims -f custom-values.yaml
```

## 安全建议

1. **修改默认密码**: 部署前修改所有默认密码
2. **启用 TLS**: 在生产环境启用 HTTPS
3. **网络策略**: 确保网络策略正确配置
4. **RBAC**: 配置适当的角色和权限
5. **密钥管理**: 使用 Kubernetes Secrets 或外部密钥管理系统

## 备份和恢复

### 备份数据

```bash
# 备份 MySQL
kubectl exec -it deployment/aims-mysql -n aims -- mysqldump -u root -p aims > backup.sql

# 备份 Milvus 数据
kubectl exec -it deployment/aims-milvus -n aims -- tar -czf /tmp/milvus-backup.tar.gz /var/lib/milvus
kubectl cp aims/aims-milvus-xxx:/tmp/milvus-backup.tar.gz ./milvus-backup.tar.gz
```

### 恢复数据

```bash
# 恢复 MySQL
kubectl exec -i deployment/aims-mysql -n aims -- mysql -u root -p aims < backup.sql
```

## 生产环境优化

1. **资源配置**: 根据实际负载调整 CPU 和内存限制
2. **存储优化**: 使用高性能存储类
3. **网络优化**: 配置适当的网络策略和 Ingress
4. **监控告警**: 集成 Prometheus 和 Grafana
5. **日志收集**: 配置 ELK 或 Loki 日志收集
6. **高可用**: 配置多副本和反亲和性规则
