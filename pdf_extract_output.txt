OpenClaw 快速上⼿指南
5 分钟完成安装和⾸次对话
⼀、准备⼯作
必需条件
Node.js：推荐 Node 24（最低 22.16+）
API 密钥：Anthropic、OpenAI、Google 等任⼀提供商
检查 Node 版本
node --version # 确保显示 v22.16+ 或更⾼
Windows ⽤户：推荐使⽤ WSL2（更稳定），原⽣ Windows 也⽀持。
⼆、快速安装
⽅式⼀：⼀键安装（推荐）
macOS / Linux：
curl -fsSL https://openclaw.ai/install.sh | bash
Windows (PowerShell)：
iwr -useb https://openclaw.ai/install.ps1 | iex
💡 说明：⾃动检测系统并安装最新版本。
⽅式⼆：NPM 安装
npm install -g openclaw
💡 说明：适合已熟悉 Node.js 的⽤户。
⽅式三：Docker
docker run -it openclaw/openclaw
三、初始化配置
运⾏配置向导
--- Page 2/3 ---
openclaw onboard --install-daemon
这个命令会：
1. 选择 AI 模型提供商
2. 输⼊ API 密钥
3. 配置 Gateway（⽹关）
4. 安装后台服务
💡 耗时：约 2 分钟完成全部配置。
四、验证安装
1. 检查 Gateway 状态
openclaw gateway status
正常输出：显示 Gateway 运⾏在 18789 端⼝
2. 打开控制⾯板
openclaw dashboard
正常情况：浏览器⾃动打开 Control UI
3. 发送第⼀条消息
在 Control UI 中输⼊任意内容，应收到 AI 回复。
五、下⼀步
任务 命令/链接
连接聊天渠道 Telegram、Discord、WhatsApp
配置配对和安全 openclaw pairing
配置 Gateway 编辑 ~/.openclaw/openclaw.json
浏览⼯具列表 ⼯具⼤全
六、⾼级选项
环境变量

# ⾃定义配置⽂件路径
export OPENCLAW_CONFIG_PATH=/custom/config.json

export OPENCLAW_STATE_DIR=/custom/state
⾮交互式安装

OpenClaw 安全与权限管理
配对、权限控制和安全配置
配对机制
什么是配对？
配对是防⽌未授权⽤户访问你的 Agent 的安全机制。
配对⽅式
⽅式 说明 命令
配对码 输⼊配对码验证 openclaw pairing
⼆维码 扫码配对 openclaw qr
配置配对
{
gateway: {
pairing: {
enabled: true,
code: "YOUR_PAIRING_CODE",
timeout: 300 // 秒
}
}
}
权限控制
Allowlist（⽩名单）
{
security: {
allowlist: [
"telegram:7601429954",
"discord:123456789"
]
}
}
Blocklist（⿊名单）
--- Page 2/4 ---
{
security: {
blocklist: [
"telegram:999999999"
]
}
}
⼯具权限
⼯具配置⽂件
Profile 包含的⼯具
full 所有⼯具（默认）
coding ⽂件 I/O、运⾏时、会话、内存、图⽚
messaging 消息、会话管理
minimal 仅 session_status
配置示例
{
tools: {
profile: "coding",
allow: ["group:fs", "browser"],
deny: ["exec"] // 拒绝优先
}
}
沙箱模式
启⽤沙箱
{
sandbox: {
enabled: true,
mode: "restrictive" // 或 "permissive"
}
}
沙箱模式
--- Page 3/4 ---
模式 说明
restrictive 严格限制，只允许显式允许的操作
permissive 宽松模式，只拒绝显式禁⽌的操作
密钥管理
存储密钥
# 设置密钥
openclaw secrets set API_KEY "your-secret-key"
# 列出密钥
openclaw secrets list
# 删除密钥
openclaw secrets delete API_KEY
在配置中引⽤
{
providers: {
anthropic: {
apiKey: "${secrets:ANTHROPIC_API_KEY}"
}
}
}
审批机制
启⽤审批
{
approvals: {
enabled: true,
mode: "interactive" // 或 "auto"
}
}
审批模式
模式 说明
--- Page 4/4 ---
interactive 需要⼿动批准
auto ⾃动批准（记录⽇志）

3. 按提示设置名称和⽤户名
4. 获取 Bot Token（格式： 123456789:ABCdefGHIjklMNOpqrsTUVwxyz ）
2. 配置 OpenClaw
# ⽅式⼀：交互式配置
openclaw channels enable telegram
# ⽅式⼆：直接编辑配置

"enabled": true,
"botToken": "YOUR_BOT_TOKEN"
}

}
}

openclaw gateway restart
4. 测试
在 Telegram 中找到你的 Bot，发送消息，应收到 AI 回复。
⚠ 注意：Bot 需要先在 Telegram 中启动（发送 /start ）。

Webhook ⾃动化
启⽤ Webhook
{
hooks: {
enabled: true,
token: "your-secret-token",
path: "/hooks",

}
}
注意：token 必填，⽤于验证请求。
Webhook 请求
curl -X POST http://localhost:18789/hooks \
-H "Authorization: Bearer your-secret-token" \
-H "Content-Type: application/json" \
-d '{
"message": "Check my email",
"wakeMode": "now",
"deliver": true,
"channel": "telegram",
--- Page 3/4 ---
"to": "7601429954"
}'
请求参数
参数 必填 说明
message 是 Agent 要处理的消息
name 否 Hook 名称（⽤于⽇志）
agentId 否 指定代理 ID
wakeMode 否 now（⽴即）或 next-heartbeat
deliver 否 是否发送响应（默认 true）
channel 否 发送渠道（默认 last）
to 否 接收者 ID
model 否 模型覆盖
timeoutSeconds 否 超时时间

"agentId": "hooks"
}

curl -X POST http://localhost:18789/hooks \
-H "Authorization: Bearer token" \
-d '{"message": "Generate daily report"}'
3. 定时外部调⽤
配合外部定时器（如 GitHub Actions）调⽤ Webhook。
Cron vs Webhook

特性 Cron Webhook
触发⽅式 时间触发 外部请求
精确度 分钟级 实时
依赖 Gateway 内置 需要外部调⽤
适⽤场景 定时任务 外部系统集成
Cron vs Heartbeat
特性 Cron Heartbeat
执⾏位置 Gateway Agent 主会话
上下⽂ 独⽴或绑定 主会话上下⽂
适⽤场景 精确时间 批量检查
说明：Heartbeat 是周期性轮询，Cron 是精确时间触发。

OpenClaw 最佳实践与案例
使⽤技巧和实际案例
基本原则
1. 最⼩权限原则：只授予必要的⼯具权限
2. 明确配对：始终启⽤配对机制
3. 定期备份：定期备份配置和数据
4. 监控⽇志：定期查看⽇志异常
推荐配置
个⼈使⽤
{

defaults: {
model: { primary: "anthropic/claude-sonnet-4-6" },
tools: { profile: "full" }
}
},
channels: {
telegram: { enabled: true }
},
security: {
pairing: { enabled: true }
}
}
团队使⽤
{

list: [
{
id: "team-assistant",
tools: { profile: "coding" }
}
]
},
security: {
allowlist: ["telegram:123456", "telegram:789012"]

}
}
使⽤场景
1. ⽇常助⼿
# 查看⽇程
openclaw message "Check my calendar today"
# 发送提醒
openclaw cron add --schedule "0 9 * * *" --command "Good morning!"
2. 代码助⼿
{

defaults: {
model: { primary: "anthropic/claude-sonnet-4-6" },
tools: {
profile: "coding",
deny: ["exec"] // 禁⽌执⾏命令
}
}
}
}
3. ⾃动化监控
# 定时检查
openclaw cron add --schedule "*/30 * * * *" \
--command "Check system status"
# Webhook 集成
curl -X POST http://localhost:18789/hooks \
-H "Authorization: Bearer token" \
-d '{"message":"Check server status"}'
性能优化
减少上下⽂

}
}
}
